# SmartRecall

SmartRecall is an AI-generated flashcard and quiz study tool. Paste in your notes, and it automatically generates a full study set: flashcards, multiple choice, true/false, and fill-in-the-blank questions, using the Gemini API.

Built for CSCI 4397/6397 (Software Engineering and AI) at the University of Central Arkansas.

## Features

- AI-generated flashcards: paste any text (notes, textbook excerpts) and get a set of Q&A flashcards
- Multiple study modes: flip cards, multiple choice, true/false, fill-in-the-blank
- Decks: organize study sets by subject or chapter
- Simplified spaced repetition: rate cards Easy, Medium, or Hard to control review frequency
- Progress dashboard: track cards studied, accuracy, and study streak
- (Stretch) AI-graded short answer mode

## Tech Stack

- Backend: Python (Flask)
- Database: SQLite
- AI: Google Gemini API
- Frontend: HTML, CSS, JavaScript
